## Descripción: 
Se aborda el manejo de operaciones repetitivas de mantenimiento en la base de datos de NovaMarket. El problema principal es que la lógica de estas modificaciones recae en la aplicación cliente, lo que genera riesgos de inconsistencia de datos y dificulta la reutilización de las operaciones.


## Objetivo:
Automatizar y centralizar estas tareas directamente en el servidor mediante procedimientos almacenados en SQL Server. La necesidad clave es asegurar la integridad de la información implementando transacciones explícitas, garantizando que un bloque de cambios se aplique por completo o se deshaga en su totalidad si ocurre algún error.
